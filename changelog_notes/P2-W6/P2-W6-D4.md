#### 9. Define the existing Oracle VM / K3s host

`instance.tf` was created with the existing Oracle VM requirements:

``` hcl

  display_name        = "weather-platform-k3s"
  shape               = "VM.Standard.A1.Flex"

  shape_config {
    ocpus         = 4
    memory_in_gbs = 24
  }

  source_details {
    source_type = "image"
    source_id   = "ocid1.image.oc1.uk-london-1.aaaaaaaafq3nyno7a72qsi6kkehqbpidfumkwwxjqapsj5l6qlojhrqn6mqa"

    subnet_id        = oci_core_subnet.weather_platform_public_subnet.id
    assign_public_ip = true

  }
}
```

current private or public IP address.
