### Why this task was required

P2-W6 introduces Terraform / Infrastructure as Code for the Weather
Intelligence Platform.

D2 establishes the existing Oracle Cloud network baseline before
Terraform resources are created for the platform infrastructure. The
objective is to identify the real OCI configuration already supporting
the K3s deployment so that the Terraform implementation can reproduce
the same infrastructure requirements without inventing or changing the
current settings.

The existing infrastructure was inspected using the OCI CLI.

No OCI infrastructure was created, modified, or deleted during D2.
