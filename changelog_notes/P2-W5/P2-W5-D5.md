### Task

- P2-W5 D5: Validate public routing, HTTPS, service isolation, and external access.
- Perform final end-to-end validation of the public Weather Intelligence Platform after completing D1–D4.
- Verify that Dashboard, FastAPI, and Airflow are reachable through the public HTTPS hostname.
- Verify that the Kubernetes Ingress routes each path to the correct backend service.

### Why this task was required

P2-W5 D1 established the public Cloudflare hostname and external access layer.

P2-W5 D2 established the Traefik Kubernetes Ingress routing.

P2-W5 D3 verified public HTTPS/TLS access and the redesigned Dashboard.

P2-W5 D4 integrated Dashboard, FastAPI, and Airflow under the public hostname.

D5 provides the final validation of the complete public deployment before closing P2-W5.

The final architecture being validated was:

```text
Public Internet
      ↓
https://ml.weather-intelligence.workers.dev/
      ↓
Cloudflare Worker
      ↓
Cloudflare Quick Tunnel
      ↓
cloudflared
      ↓
K3s Traefik
      ↓
weather-platform-ingress
      ├── /          → prediction-dashboard-service:8051
      ├── /api       → fastapi-service:8000
      └── /airflow   → airflow-apiserver:8080
```

The validation also confirms that FastAPI remains a Kubernetes `ClusterIP` service rather than requiring a dedicated public NodePort.

#### 7. Validate service configuration and isolation

The backend services were checked with:

```bash

  prediction-dashboard-service \
  fastapi-service \
  airflow-apiserver
```

The result was:

```text
NAME                           TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)          AGE
prediction-dashboard-service   NodePort    10.43.199.248   <none>        8051:30002/TCP   10d
fastapi-service                ClusterIP   10.43.169.185   <none>        8000/TCP         10d
airflow-apiserver              NodePort    10.43.174.147   <none>        8080:30080/TCP   10d
```

This confirmed the final service exposure model:

```text
Dashboard → NodePort 30002
FastAPI   → ClusterIP 8000
Airflow   → NodePort 30080
```

The public Ingress routes through the Kubernetes service ports:

```text
/          → Dashboard :8051
/api       → FastAPI :8000
/airflow   → Airflow :8080
```

FastAPI therefore remains isolated as a ClusterIP service while still being publicly reachable through the controlled Traefik ingress path.
