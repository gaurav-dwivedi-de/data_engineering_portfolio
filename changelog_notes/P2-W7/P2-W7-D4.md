### Why this task was required

P2-W7 D3 established the Spark MLlib model development pipeline and produced
trained Linear Regression and Random Forest models.

D4 was required to evaluate those trained models against the fixed
chronological test dataset created during D3. Both models needed to be
evaluated against exactly the same 9,171 test observations using consistent
regression metrics.

The prediction output also needed to be checked for row-count integrity.
The dataset contains three cities at each timestamp, so `time` alone is not a
unique observation identifier. This became important when the initial
prediction outputs were joined.

The validated evaluation results were then persisted as a machine-readable
artifact so that they can be reused during the later MLflow work in P2-W8.

#### 3. Identify the prediction-row duplication issue

The test dataset contains three cities for every timestamp. Therefore,
`time` and `target_temp_next_hour` are not guaranteed to uniquely identify an
observation.

Joining the Linear Regression and Random Forest prediction DataFrames on
those two columns caused multiple matching rows to be combined. This
increased the prediction output from 9,171 rows to 9,279 rows.

The resulting 9,279-row prediction artifact was therefore considered invalid
for the intended evaluation.

The metrics calculated from that invalid dataset were explicitly discarded:

``` text
MLlib Linear Regression
RMSE: 0.571643
MAE: 0.404420
R2: 0.985456

MLlib Random Forest
RMSE: 1.164728
MAE: 0.684452
R2: 0.939622
```

These values were not used as the final D4 results.

#### 4. Correct the prediction and evaluation method

The evaluation was corrected by transforming the original test DataFrame
independently with each trained model rather than joining the two prediction
outputs.

The command used was:

``` text
(.venv) gaurav@gauravs-Mac-mini data_engineering_portfolio % python -c 'from pyspark.sql import SparkSession; from pyspark.ml.regression import LinearRegressionModel, RandomForestRegressionModel; from pyspark.ml.evaluation import RegressionEvaluator; spark=SparkSession.builder.master("local[*]").appName("P2-W7-D4-Evaluation").getOrCreate(); test=spark.read.parquet("./w7_feature_engineering/data/processed/w7_mllib_test.parquet"); lr=LinearRegressionModel.load("./w7_feature_engineering/models/mllib_linear_regression"); rf=RandomForestRegressionModel.load("./w7_feature_engineering/models/mllib_random_forest"); lr_predictions=lr.transform(test); rf_predictions=rf.transform(test); print("Test rows:",test.count()); print("Linear Regression predictions:",lr_predictions.count()); print("Random Forest predictions:",rf_predictions.count()); evaluator=RegressionEvaluator(labelCol="target_temp_next_hour",predictionCol="prediction"); evaluator.setMetricName("rmse"); lr_rmse=evaluator.evaluate(lr_predictions); rf_rmse=evaluator.evaluate(rf_predictions); evaluator.setMetricName("mae"); lr_mae=evaluator.evaluate(lr_predictions); rf_mae=evaluator.evaluate(rf_predictions); evaluator.setMetricName("r2"); lr_r2=evaluator.evaluate(lr_predictions); rf_r2=evaluator.evaluate(rf_predictions); print(); print("MLlib Linear Regression"); print("RMSE:",round(lr_rmse,6)); print("MAE:",round(lr_mae,6)); print("R2:",round(lr_r2,6)); print(); print("MLlib Random Forest"); print("RMSE:",round(rf_rmse,6)); print("MAE:",round(rf_mae,6)); print("R2:",round(rf_r2,6)); spark.stop()'
```

### Challenges and Resolutions

#### Challenge 1: Prediction output contained more rows than the test dataset

The initial prediction join produced 9,279 rows instead of the expected
9,171 rows.

The cause was the use of `time` and `target_temp_next_hour` as join keys in a
dataset containing three cities per timestamp.

**Resolution:** The joined prediction output was rejected. Each model was
evaluated independently against the original test DataFrame so that the
9,171-row test-set cardinality was preserved.

#### Challenge 2: Initial evaluation metrics were invalid

The first evaluation produced metrics from the duplicated 9,279-row
prediction dataset.

**Resolution:** Those metrics were discarded. The models were reevaluated
directly against the original 9,171 test observations.

#### Challenge 3: Spark environment warnings appeared during evaluation

Spark reported the following environment warnings during the corrected
evaluation:

**Resolution:** The Spark jobs completed successfully. The warnings were
