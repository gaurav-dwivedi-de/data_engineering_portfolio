### Challenges and Resolutions

#### 1. pytest was not installed in the project virtual environment

**Challenge**

The first attempt to execute the D5 test suite failed because pytest was not installed in the active `.venv`:

```text
/Users/gaurav/Documents/Projects/data_engineering_portfolio/.venv/bin/python: No module named pytest
```

**Resolution**

Installed pytest directly into the active project virtual environment:

```bash
python -m pip install pytest
```

Installed version:

```text
pytest-9.1.1
```

The test suite could then be executed normally.

#### 2. Spark ML model-loading tests failed because of SparkContext handling

**Challenge**

The initial test implementation produced 8 passing tests and 3 failures.

Both persisted model-loading tests failed because Spark ML model loading requires an active Spark context. The subsequent prediction validation test also encountered:

```text
Only one SparkContext should be running in this JVM
```

The failures were therefore related to the test's Spark session lifecycle rather than corrupted or invalid MLlib model artifacts.

**Resolution**

The test suite was changed to use a session-scoped Spark fixture. Spark-dependent tests now share one Spark session for the complete pytest session instead of repeatedly creating independent Spark contexts.

After this correction:

```text
10 passed, 1 failed
```

remained, isolating the final issue to the evaluation JSON assertion.

#### 3. Evaluation JSON test expected the wrong structure

**Challenge**

The evaluation validation test expected the model names directly at the root of the JSON object:

```text
evaluation["linear_regression"]
evaluation["random_forest"]
```

The actual generated evaluation artifact stores both models under the `models` object:

```json
{
  "framework": "Spark MLlib",
  "test_rows": 9273,
  "models": {
    "linear_regression": {},
    "random_forest": {}
  }
}
```

This caused:

```text
AssertionError: assert 'linear_regression' in evaluation
```

**Resolution**

The test was corrected to validate:

```text
evaluation["models"]["linear_regression"]
evaluation["models"]["random_forest"]
```

It also validates the expected `framework` value and the `rmse`, `mae`, and `r2` metrics for both models.

#### 4. Final validation confirmed all D5 checks

**Challenge**

**Resolution**
