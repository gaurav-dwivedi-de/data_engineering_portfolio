### Why this task was required

P2-W7 introduces Spark MLlib into the existing Weather Intelligence
Platform. After D1 validated the source data and D2 created the
Spark-compatible clean feature dataset, D3 was required to train the
first MLlib regression models.

The model development stage establishes Spark MLlib implementations of
the two regression approaches already relevant to the project:

-   Linear Regression.
-   Random Forest Regression.

A chronological 80/20 split was used so that the model is trained only
on earlier observations and evaluated later on unseen observations in
D4.

The existing scikit-learn production model path was not replaced during
D3. The MLlib models are being developed as a separate comparative
implementation.

### Challenges and Resolutions

#### Challenge 1: Random Forest exceeded local Java heap memory

The initial Random Forest configuration of 100 trees and maximum depth 10
caused Spark to terminate the training job with a Java heap-space
exception.

The failure occurred during Spark MLlib tree split calculation.

**Resolution:** The model configuration was reduced to 50 trees and
maximum depth 8, and the Spark driver was allocated 4 GB of memory. The
same 36,681-row training dataset and 27-feature vector were retained.
The revised model trained successfully in 3.30 seconds.

#### Challenge 2: Linear Regression reported numerical-stability warnings

Spark reported that `regParam = 0.0` may cause numerical instability and
that the Cholesky solver failed because of a singular covariance matrix.

**Resolution:** Spark automatically retried using its Quasi-Newton solver.
The Linear Regression model completed successfully and was saved. No
changes to the D2 feature dataset were required.

#### Challenge 3: MLlib model development needed to remain separate from evaluation

The model training stage should not use the held-out test data for model
development.

**Resolution:** Both models were trained exclusively on the 36,681-row
training dataset. The 9,171-row test dataset was preserved for P2-W7 D4.
