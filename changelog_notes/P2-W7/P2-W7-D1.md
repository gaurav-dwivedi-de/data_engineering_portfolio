#### 2. Validate target alignment

The existing `target_temp_next_hour` column was compared against the
next `temperature` value within the same city.

The command used was:

``` text
(.venv) gaurav@gauravs-Mac-mini data_engineering_portfolio % python -c 'import pyarrow.parquet as pq; import pandas as pd; import numpy as np; df=pq.read_table("./w7_feature_engineering/data/processed/w7_features_final.parquet").to_pandas(); df["time"]=pd.to_datetime(df["time"]); df["_city_key"]=df["city_London"].astype(int).astype(str)+"_"+df["city_Manchester"].astype(int).astype(str); df=df.sort_values(["_city_key","time"]).reset_index(drop=True); expected=df.groupby("_city_key")["temperature"].shift(-1); valid=expected.notna(); mismatches=(~np.isclose(df.loc[valid,"target_temp_next_hour"].astype(float),expected.loc[valid].astype(float),rtol=1e-6,atol=1e-6)).sum(); print("Target comparisons:",int(valid.sum())); print("Target mismatches:",int(mismatches))'
```

The output was:


All 45,861 valid target comparisons matched the expected next

### Challenges and Resolutions

#### Challenge 1: Dataset size changed from the earlier validation snapshot

The current W7 dataset contains 45,864 rows rather than the earlier
45,720-row snapshot.

**Resolution:** The dataset is downloaded and updated daily. The current
row count was treated as authoritative. The timestamp structure
confirmed that the additional data is consistent with the ongoing daily
ingestion.

#### Challenge 2: The W7 feature dataset contains temporal boundary rows

Lag features and the next-hour target cannot represent valid
historical/next-hour observations at every boundary of each city time
series.

**Resolution:** The boundary rows were identified for exclusion from the
separate MLlib dataset. With three cities, the current preparation
requires 12 boundary rows to be excluded, leaving an expected 45,852
clean MLlib rows.

#### Challenge 3: Target correctness needed to be verified before MLlib training

The target column had to be confirmed against the actual next
temperature observation within each city.

**Resolution:** The target was compared against a city-grouped
`shift(-1)` reference. All 45,861 valid comparisons matched, with zero
mismatches.

##### I loaded the Parquet dataset with PyArrow/Pandas, grouped the observations by city and timestamp, checked that each timestamp had the expected number of city observations, verified hourly continuity using groupby().diff(), and independently reconstructed the next-hour target using groupby().shift(-1) to verify that the stored target was correctly aligned.
